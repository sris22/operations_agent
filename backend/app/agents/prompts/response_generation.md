Generate a clear, concise response for the customer-support operator based on all gathered information.

1. Summary of findings
2. Key data points from tool results
3. Recommended action (if any)
4. Next steps for the operator

- If tools failed, mention which ones and what that means

- If you retrieved relevant knowledge, cite it
